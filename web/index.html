Langkah Instalasi di Odroid C2 / STB HG680P

Cara pasang dan update aplikasi di server Linux / DietPi

sudo curl -sSL https://raw.githubusercontent.com/faisalfa123/DompetMungil/main/install.sh | sudo bash
  1. Buka terminal SSH di Odroid C2 / DietPi Anda.
  2. Salin dan jalankan perintah 1-baris di atas. Skrip akan mengunduh biner ARM64 otomatis tanpa kompilasi berat.
  3. Pilih folder instalasi (tekan Enter untuk /opt/dompetmungil) dan port 1234.
  4. Buka di HP Anda melalui http://[IP-Odroid]:1234 dan buat akun admin pertama!

📖 Panduan Lengkap Awal Sampai Akhir

Pelajari alur penggunaan DompetMungil langkah demi langkah (Registrasi, Maskot, Saldo, Anggaran, Celengan Ayam, Gmail, hingga Backup):

1. Offline-First & Keamanan STB

Jika server Odroid/HG680P Anda sedang mati atau terhenti oleh OOM killer karena beban berat, aplikasi tetap bisa dipakai mencatat. Data disimpan aman di HP Anda dan otomatis disinkronkan saat server santai kembali.

2. Enkripsi Database Khusus

Catatan pengeluaran, pemasukan, dan mutasi bank Anda dienkripsi secara penuh dengan standar AES-256 menggunakan kunci rahasia per-perangkat. Aplikasi luar di STB tidak akan dapat membaca isi catatan keuangan Anda.

3. Cara Pasang di HP (PWA)

Buka menu browser Chrome/Safari Anda, lalu pilih "Tambahkan ke Layar Utama" (Add to Home Screen) untuk mendapatkan pengalaman seperti aplikasi bawaan toko aplikasi.
