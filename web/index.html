Google OAuth (Aplikasi Tertaut)

Masuk resmi & terdaftar di menu "Aplikasi Tertaut" Akun Google Anda

✨ Muncul di Akun Google Anda:
Setelah tautan ini aktif, DompetMungil akan otomatis terdaftar di halaman Aplikasi Tertaut (myaccount.google.com/linkedapps) persis seperti GitHub, Claude, dan Shopee!

Masukkan Client ID dari Google Cloud Console (wajib pilih tipe Desktop app agar bebas dari error IP/domain):

📖 Langkah 1 Menit Buat Client ID (Tipe Desktop App):
  1. Buka Google Cloud Console.
  2. Klik tombol + CREATE CREDENTIALS di bagian atas » Pilih OAuth client ID.
  3. Pada menu dropdown Application type, pilih: Desktop app (JANGAN pilih Web application).
  4. Beri nama: DompetMungil lalu klik CREATE.
  5. Google akan langsung memberikan Client ID tanpa meminta URL asal atau domain!
  6. Salin Client ID tersebut, tempelkan ke kolom di atas, lalu klik Simpan ID.

🎮 Tur Interaktif (Game Spotlight)

Ingin melihat kembali sorotan langkah demi langkah di dashboard seperti tutorial game?

1. Offline-First & Keamanan STB

Jika server Odroid/HG680P Anda sedang mati atau terhenti oleh OOM killer karena beban berat, aplikasi tetap bisa dipakai mencatat. Data disimpan aman di HP Anda dan otomatis disinkronkan saat server santai kembali.

2. Enkripsi Database Khusus

Catatan pengeluaran, pemasukan, dan mutasi bank Anda dienkripsi secara penuh dengan standar AES-256 menggunakan kunci rahasia per-perangkat. Aplikasi luar di STB tidak akan dapat membaca isi catatan keuangan Anda.

3. Cara Pasang di HP (PWA)

Buka menu browser Chrome/Safari Anda, lalu pilih "Tambahkan ke Layar Utama" (Add to Home Screen) untuk mendapatkan pengalaman seperti aplikasi bawaan toko aplikasi.
